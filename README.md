# 龙门令 · 嘉峪关双路线 AR 游戏原型

可在手机浏览器运行的双语交互原型，完整串起“游客身份选择 → 双路线地图 → 实景扫描 → NPC 任务 → 碎片与积分 → 礼物 / 优惠券兑换”。页面持续保留嘉峪关实景照片和 AR 扫描框；任务点用景区照片、拍摄提示和 NPC 互动演示。

## 运行

在项目目录启动本地 HTTP 服务：

    python -m http.server 8080

访问 http://localhost:8080。浏览器的摄像头和定位通常需要 HTTPS 或 localhost。当前扫描可模拟识别并推进剧情；摄像头功能会请求手机权限。

## 已实现

- 游客可选择大明边军或西域商队，两种身份分别保存任务与兑换进度。
- 中英文切换覆盖身份选择、路线、任务、碎片、优惠券和扫描窗口。
- 两条路线叠加在同一张关城卫星影像示意图上，可区分颜色和序号查看。
- 每个任务均包含实景拍照建议、角色 NPC、互动问题、积分和一枚龙门令碎片。
- 每条路线完成五项任务后合成完整龙门令，可登记限量礼物兑换；未完成时可用积分兑换旅拍、美食或文创优惠券。
- 摄像头预览、扫描示意、定位请求和本机进度保存均可交互。扫码、奖励、库存与景区身份核验尚为演示逻辑。

## 两条建议动线

**大明边军**：东闸门验明正身 → 游击将军府接令 → 光化楼辨认巡更暗记 → 柔远楼望楼协巡 → 嘉峪关城楼合令验印。

**西域商队**：东闸门外侧商道 → 文昌阁筹措通关文牒 → 外城开阔地与长城根基古道 → 罗城 / 西瓮城出关缓冲区 → 西门外戈壁观景点。

西域商队将外城开阔地与长城根基古道合并为一个任务站，沿最外侧城墙和内城墙之间的开阔夹道连续西行，再进入罗城 / 西瓮城缓冲区；这样保留五枚任务碎片，同时把路线延伸到不同游览空间。

## 上线前需要现场核验

西门外戈壁观景点和长城根基古道在界面中标为拟议点位。需由景区确认入口、步行可达性、文物保护边界、旺季人流组织、无障碍与安全条件，再确定 GPS 坐标和单向动线。正式上线还需布设经许可的二维码 / NFC 标记，接入游客账号 / 票务核验、服务器任务状态、兑换库存与优惠规则，并补全图片授权及隐私说明。

故事人物、暗号和兑换数值为演示内容，不构成历史陈述或景区运营承诺。任务答题、积分和兑换状态保存在当前浏览器本地。

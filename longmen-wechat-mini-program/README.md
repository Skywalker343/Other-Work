# 龙门令 · 微信小程序原型

这是原有「龙门令」手机端 AR 游戏的微信小程序独立实现。请在微信开发者工具中导入本目录；原网页版本的文件与代码保留在上级目录，没有被改写。

## 导入与运行

1. 打开微信开发者工具，选择「导入项目」，项目目录选本文件夹。
2. 将项目配置中的 touristappid 替换为你有权限使用的 AppID，或在开发者工具内选择可用的测试 AppID。
3. 首次预览定位功能时，在小程序后台按微信要求完成用户隐私保护指引和位置权限声明。
4. 使用开发者工具预览或真机预览。无需搭建服务端；当前游客进度保存在设备本地。

项目使用微信原生页面、组件、WXML、WXSS 和小程序 API。微信官方示例仓库可参考相机扫码、定位等 API 的使用方式：[wechat-miniprogram/miniprogram-demo](https://github.com/wechat-miniprogram/miniprogram-demo)。AR 与位置寻宝的开源产品思路可参考 [AR.js](https://github.com/AR-js-org/AR.js) 和 [GP-Scavenger](https://github.com/StoutsHonor/GP-Scavenger)；本项目没有复制这些项目的代码或素材。

## 功能

- 游客在「大明边军」和「西域商队」之间选择身份，两种身份分别保存完成任务、积分、碎片和优惠券状态。
- 每个页面都保留嘉峪关实景照片、AR 扫描框、龙门令线索、定位入口和底部扫描入口；支持中文 / English 切换。
- 支持微信扫码读取任务二维码；二维码内容需包含当前身份任务编号，边军为 g1–g5，商队为 c1–c5。另提供模拟扫描，便于没有现场标记时体验流程。
- 每条路线有五个 NPC 互动任务。回答线索问题后获得该任务积分和一枚龙门令碎片；集齐五枚后解锁完整令牌与限量礼物登记界面。
- 积分可用于演示兑换旅拍、美食、文创优惠券。路线、任务、积分和礼物状态仅保存在本机。

## 两条游览路线

**大明边军**：东闸门验明正身 → 游击将军府接令 → 光化楼巡查 → 柔远楼巡查 → 嘉峪关城楼。

**西域商队**：东闸门外侧商道 → 文昌阁筹措通关文牒 → 外城开阔地及长城根基古道绕行 → 罗城 / 瓮城出关缓冲区 → 西门外大漠戈壁视界。

路线参考在线[高德地图景区位置](https://ditu.amap.com/place/B0HDHGB3WJ)、[OpenStreetMap / Mapcarta 景区地图](https://mapcarta.com/W178837941)，并对照含有景区游览图的[游客路线介绍](https://sizheng.org/travel/jiayu-pass/)及[景区建筑分布与入口信息](https://you.ctrip.com/sight/jiayuguan284/11049.html)确认地理关系。小程序底图沿用原型素材中的关城卫星影像；两条彩色路线是据上述地图绘制的策划示意线，并非实测导航轨迹。游客取景主题参考[游击将军府游客实拍与攻略](https://hk.trip.com/moments/poi-mansion-of-guerrilla-general-84068/)和[柔远楼景点与游客照片](https://you.ctrip.com/sight/jiayuguan284/51748.html)。景区实景照片、地图和具体点位的使用授权均需由景区确认。西门外戈壁视界、长城根基古道等点位为提议内容，启用前需现场核验开放范围、安全性及文物保护要求。

## 原型范围

扫描页以景区照片作为 AR 实景演示背景，微信扫码器可读取经部署的二维码；它尚未接入实时图像识别、NFC、地理围栏或导航轨迹。没有现场二维码时可用模拟扫描体验任务。定位仅演示获取位置权限，目前不用于自动判定任务完成。

积分、优惠券、礼物库存和兑换均是本机演示数据，不具备景区核销能力。正式运营需要景区批准的地图和图片授权、现场动线与点位踏勘、二维码 / NFC 布点、服务器账号与任务状态、优惠规则与兑换库存，以及隐私合规配置。游戏故事与 NPC 对话为虚构体验内容，不作为历史事实说明。
